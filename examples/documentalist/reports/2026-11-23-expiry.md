# Documentalist, 2026-11-23: reader end dates and `docs share verify`

A dated record of the run behind issues #264 and #265. What it changed in OpenGuildKit is in [Project documentation and sharing](../../../docs/documentation.md#compare-the-register-with-a-portal).

Instances, all on 127.0.0.1, built with `npm run build` and run with `next start`, Next.js 16.4.3 on Node.js v26.13.0 under macOS (the README recommends Node.js 22; this run did not use it):

| Port | Documentalist | `DOCUMENTALIST_URL` |
|---|---|---|
| 3000 | [PR #25](https://github.com/azerothl/documentalist/pull/25) at `7dbc66e` (`69bc2b0` and its tests, on top of `947429b`; not merged on the day) | `http://127.0.0.1:3000` |
| 3001 | `947429b` (main) | `http://127.0.0.1:3001` |
| 3002, behind a TLS proxy on 3443 | PR #25 at `7dbc66e` | `https://127.0.0.1:3443`, secure cookies |

SMTP went to a local sink written with the Python standard library. Every Node process ran with a guard that refuses any connection off the loopback interface; it refused `registry.npmjs.org:443` twice, at the start of each `next build`. The fonts were mocked at build time as on 2026-11-22. The TLS proxy used a certificate from a test authority created for the run. OpenGuildKit ran from source on this branch with Python 3.15.2. The reader used a fresh Playwright 1.64.1 Chromium context; the owner's settings were driven in another context carrying the administrator session from an HTTP sign-in. `docs share verify` ran in a pseudo-terminal that typed the password of a test editor account at the prompt. All addresses end in `@example.test`; the test passwords stayed outside the repository.
