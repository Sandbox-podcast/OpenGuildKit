# Code of conduct

OpenGuildKit adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in issues, pull requests, discussions and any space where people represent the project.

In short: be respectful, assume good faith, critique work rather than people, and accept that maintainers and stewards will remove behavior that harms others.

## Reporting

Report incidents privately: open the repository's **Security** tab, choose **Report a vulnerability**, and start the title with `Conduct:`. Only the maintainers can read these reports; OpenGuildKit has one maintainer today. The maintainer acknowledges a report within 14 days, responds following the Contributor Covenant enforcement guidelines and keeps the reporter's identity confidential.
