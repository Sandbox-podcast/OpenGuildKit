# Deliberation

Read this file in step 3 of SKILL.md when `openguildkit task deliberate ID` lists objections.

Each response names the `objections` it answers and a `position`: `maintain`, `amend` (say how the position changes) or `concede`. `maintain` and `amend` cite `evidence_refs` from the board's own evidence list, counted from 1. An objection is resolved when one board concedes (the other board then need not answer it) or both amend; when one stays open, write in `decision_needed` the decision the person must take.
